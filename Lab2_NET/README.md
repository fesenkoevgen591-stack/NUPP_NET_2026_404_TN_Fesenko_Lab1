# Лабораторна робота №2 (.NET) — ТН

Асинхронний generic CRUD, ConcurrentDictionary, IEnumerable, LINQ, Parallel.For, пагінація, JSON, lock, SemaphoreSlim, AutoResetEvent.

## Запуск

```bash
dotnet run --project Lab2_NET.csproj
```

Створюється 1000 об'єктів Bus, друкується статистика і приклади CRUD, у `bin/Debug/net8.0/buses.json` зберігається 999 об'єктів після демонстраційного видалення.
