# Лабораторна робота №2 (.NET)

Асинхронний generic CRUD, ConcurrentDictionary, IEnumerable, LINQ, Parallel.For, пагінація, JSON, lock, SemaphoreSlim, AutoResetEvent.

## Запуск із папки Lab2

```bash
dotnet run --project Lab2_NET
```

Програма демонструє CRUD для ламп і автобусів. Під час демонстрації з автобусами створюється 1000 об’єктів `Bus`. Після видалення одного об’єкта програма зберігає решту в `Lab2_NET/bin/Debug/net8.0/buses.json`.
